Reihenfolge innerhalb jedes Kapitels (oberhalb von Bonus/Abschluss):
1. **DIAGNOSE** — Accent: Sage `var(--sage)` / dunkelgrün `#2D4F3C`. Linke 6px-Border in Sage.
2. **LÖSUNG** — Accent: Terracotta `var(--terracotta)` `#C4836E`. Linke 6px-Border in Terracotta.
3. **ÜBUNGEN** — Accent: Warmes Gold/Cream `#D4A574`. Linke 6px-Border in Gold.
4. **TRANSFORMATIONSZIELE** — Accent: Mauve `var(--mauve)` `#9B7FA4`. Linke 6px-Border in Mauve.

Jedes Element ist eine eigene Karte/Section mit:
- linker farbiger Border-Stripe (6px)
- Label oben in Uppercase, letter-spacing 2px
- Body unter Label, ruhige Typografie (Lato 16/1.8)

Diese Reihenfolge ist verbindlich für ALLE Module (01–10 + Bonus D/E/F). Inhaltlich werden die Texte vom User pro Kapitel-Element separat geliefert; nicht erfinden, wenn Inhalt fehlt — nachfragen.
